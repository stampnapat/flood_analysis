2Data Classification คืออะไรสไลด์ 5–7

📘 นิยาม (Definition)
  • Data Classification (การจำแนกประเภทข้อมูล) คือเทคนิคแบบ supervised learning ที่ใช้ ทำนายหมวดหมู่ (category) ของข้อมูลใหม่ โดยอาศัย training data
  • เชิงเทคนิค: หา model ที่ทำนาย class attribute ซึ่งเป็นค่าเชิงหมวดหมู่ ในรูป ฟังก์ชันของค่าของ attribute อื่น ๆ

องค์ประกอบที่ต้องจำ

  • ได้รับ collection of records = training set
  • แต่ละ record มี attributes หลายตัว
  • หนึ่งใน attribute คือ class attribute (label) = สิ่งที่ต้องทำนาย

เป้าหมายและการวัดผล สไลด์ 6

  • เป้าหมาย: ข้อมูลที่ไม่เคยเห็น (unseen records) ต้องถูกกำหนดคลาสให้ แม่นยำที่สุด
  • ใช้ test set เป็นตัววัด accuracy ของโมเดล
  • โดยทั่วไปแบ่งข้อมูลเป็น training set (สร้างโมเดล) และ test set (ตรวจสอบโมเดล)

ตัวอย่างงาน Classification สไลด์ 7

  • จำแนกธุรกรรมบัตรเครดิตว่า legitimate หรือ fraudulent
  • จัดหมวดข่าวเป็น finance / weather / entertainment / sports
  • จำแนกโครงสร้างทุติยภูมิของโปรตีนเป็น alpha-helix / beta-sheet / random coil

6Logistic Regressionสไลด์ 14–24

📘 นิยาม
  • Logistic Regression (การถดถอยโลจิสติก) ทำนาย ตัวแปรตามเชิงหมวดหมู่ (categorical dependent variable) จากตัวแปรอิสระ (independent variables) หลายตัว
  • เป็นเทคนิคแบบ binary-classification ที่ทำนาย ความน่าจะเป็น ที่ข้อมูลหนึ่งจะอยู่ในคลาสใดคลาสหนึ่งจากสองคลาส
  • ใช้ฟังก์ชันคล้าย sigmoid function ในการทำนายผลลัพธ์

6.1 จากเส้นตรงสู่เส้นโค้ง sigmoid สไลด์ 14–17

ln p1 − p = b0 + b1X1
สัญลักษณ์ความหมาย
pความน่าจะเป็นที่จะอยู่ในคลาส "1" (เช่น took up offer = YES)
p / (1 − p)odds — อัตราส่วนของโอกาสเกิดต่อโอกาสไม่เกิด
ln(p/(1−p))logit — ค่าที่ทำให้ฝั่งขวาเป็นสมการเชิงเส้นได้
b0, b1จุดตัดแกน (intercept) และสัมประสิทธิ์ของตัวแปร X1

6.2 Logistic Regression หลายตัวแปร สไลด์ 18

ln p1 − p = b0 + b1X1 + b2X2 + b3X3 + b4X4

6.3 หาเส้นที่ดีที่สุดด้วย Maximum Likelihood สไลด์ 19–21

  • Logistic regression ใช้ Maximum Likelihood หาเส้นที่ดีที่สุด (ไม่ใช่ least squares แบบ linear regression)
  • วิธีคิด likelihood ของแต่ละเส้น (สไลด์ 20): คูณความน่าจะเป็นของทุกจุด
    • จุด YES ใช้ p: 0.03 × 0.54 × 0.92 × 0.95 × 0.98
    • จุด NO ใช้ (1 − p): × (1−0.01) × (1−0.04) × (1−0.10) × (1−0.58) × (1−0.96)
    • ผลลัพธ์: Likelihood = 0.00019939
  • เส้นที่ได้ค่ามากที่สุด = Best Curve ⇐ Maximum Likelihood

7K-Nearest Neighbor (KNN)สไลด์ 25–28

📘 นิยาม
  • KNN — เทคนิคการค้นหาเพื่อนบ้านที่ใกล้ที่สุด k ตัว เป็น supervised learning ที่ใช้ได้ทั้งงาน classification และ regression
  • หลักการ: "birds of a feather flock together" — นกประเภทเดียวกันมักบินรวมฝูง คือข้อมูลที่มีคุณลักษณะคล้ายกันมักอยู่คลาสเดียวกัน
  • KNN หา คลาสที่พบบ่อยที่สุด ในกลุ่มเพื่อนบ้าน K ตัวที่ใกล้ที่สุด แล้วกำหนดคลาสนั้นให้ข้อมูลใหม่

  2. Distance Metric สำหรับคำนวณระยะระหว่าง record

ตระกูล Minkowski distance สไลด์ 36

ระยะทางระหว่างวัตถุที่มีตัวแปรต่อเนื่อง โดย i = (xi1, …, xip) และ j = (xj1, …, xjp) เป็นข้อมูล p มิติ และ q เป็นจำนวนเต็มบวก

  • ในโค้ด scikit-learn เขียนเป็น metric = 'minkowski', p = 2 ซึ่ง คือ Euclidean
  • ข้อสอบชอบให้คำนวณ Euclidean distance ด้วยมือจากจุด 2 มิติ

11การเลือกค่า kสไลด์ 37–39

หลักการเลือก สไลด์ 37

  • k คือจำนวนเพื่อนบ้านที่ใช้จำแนก record ใหม่
  • K=1 ใช้เรคคอร์ดที่ใกล้ที่สุดเพียงตัวเดียว, K=5 ใช้ 5 ตัวที่ใกล้ที่สุด
  • โดยทั่วไปเลือก k ที่ให้ error rate ต่ำที่สุดใน validation data
  • โดยทั่วไปเลือก k เป็นเลขคี่ (odd value)

ผลของขนาด k สไลด์ 38–39

  • k เล็กเกินไป → ไวต่อ noise points
  • k ใหญ่เกินไป → เพื่อนบ้านอาจกินพื้นที่ไปถึง จุดของคลาสอื่น
ค่า kได้อะไรเสียอะไร
Low k (1, 3, …)จับ โครงสร้างเฉพาะที่ (local structure) ของข้อมูลได้ดีจับ noise ติดมาด้วย
High kทำให้ผลลัพธ์ เรียบขึ้น (smoothing) ลด noiseอาจ พลาดโครงสร้างเฉพาะที่
k = n (ทั้งชุดข้อมูล)กรณีสุดขั้ว — เท่ากับ "naïve rule" คือจำแนกทุก record ตาม คลาสที่มีจำนวนมากที่สุด (majority class) เหมือนกันหมด
⭐ จุดที่มักออกสอบ
  • คำถามคลาสสิก: "k เล็กไป/ใหญ่ไป เกิดอะไรขึ้น" — ตอบ k เล็ก = ไวต่อ noise (overfit), k ใหญ่ = เรียบเกินไปจนพลาด local structure (underfit) และสุดขั้วที่ k = n กลายเป็น naïve rule
  • อีกข้อที่ออกบ่อยคือ ทำไมต้องเลือก k เป็นเลขคี่ (ตอบ: กันคะแนนเสียงเสมอในปัญหา 2 คลาส)

14.1 Shortcomings และ Curse of Dimensionality สไลด์ 46–47

  • ระยะทางที่คาดหวังไปยังเพื่อนบ้านที่ใกล้ที่สุด เพิ่มขึ้นตามจำนวนมิติ p — เมื่อ predictor เยอะมาก ทุก record จะ "อยู่ไกลกันไปหมด"
  • ใน training set ขนาดใหญ่ ใช้ เวลานาน ในการคำนวณระยะทางไปยังทุกจุดแล้วหาตัวที่ใกล้ที่สุด
  • สองข้อนี้รวมกันเรียกว่า "curse of dimensionality"
  • ทางแก้: ลดมิติของ predictors เช่นด้วย PCA · และต้อง หาค่า k ที่เหมาะสม (Optimal K)
✅ สรุปการทำงานของ KNN สไลด์ 47
  1. หาระยะทางระหว่าง record ที่จะจำแนก กับ record อื่น ๆ ทั้งหมด
  2. เลือก k records ที่ใกล้ที่สุด
  3. จำแนกตาม majority vote ของเพื่อนบ้าน (หรือใช้ ค่าเฉลี่ย ถ้าเป็นงาน prediction)
  4. ระวัง "curse of dimensionality" — ต้อง จำกัดจำนวน predictors

Precision (p) = aa + c = TPTP + FP      Recall (r) = aa + b = TPTP + FN
F-measure (F) = 2rpr + p = 2a2a + b + c
ตัวชี้วัดนิยามข้อดี / ใช้เมื่อใด
Precisionอัตราส่วนของ positive ที่ทำนายถูก (TP) ต่อ ทุกอย่างที่ทำนายว่าเป็น positive (TP + FP)เน้นความสามารถ หลีกเลี่ยง false positives
สำคัญเมื่อ false positive มีต้นทุนสูง เช่น การกรองสแปม (เมลสำคัญถูกทิ้งลงถังสแปม)
Recallอัตราส่วนของ positive ที่ทำนายถูก (TP) ต่อ positive จริงทั้งหมด (TP + FN)เน้นความสามารถ หา true positives ให้ครบ
สำคัญเมื่อการพลาด positive ยอมรับไม่ได้ เช่น การวินิจฉัยโรค
สำคัญในสถานการณ์ที่ false negative มีต้นทุนสูง
F1-Scoreค่าเฉลี่ยฮาร์มอนิก (harmonic mean) ของ precision และ recall รวมข้อมูลทั้งสองเป็นค่าเดียวตัวเลือกที่ สมดุล สำหรับชุดข้อมูลไม่สมดุล (imbalanced) หรือเมื่อทั้ง precision และ recall สำคัญพอ ๆ กัน
⭐ จุดที่มักออกสอบ
  • ต่างกันแค่ ตัวส่วน: Precision ÷ คอลัมน์ที่ทำนายว่าบวก (a + c), Recall ÷ แถวที่เป็นบวกจริง (a + b)
  • วิธีจำ: Precision = "ที่เตือนมา จริงกี่อัน" · Recall = "ของจริงทั้งหมด จับได้กี่อัน"
  • ข้อสอบมักให้ confusion matrix แล้วให้คำนวณทั้งสามค่า

✅ สรุปทั้งบทใน 12 บรรทัด
  • Classification = งาน supervised ที่ทำนาย คลาสเชิงหมวดหมู่ ของข้อมูลใหม่จาก training data
  • แบ่งงานได้เป็น binary / multiclass / multi-label / hierarchical
  • กระบวนการมาตรฐาน: สร้างโมเดล → ประเมินด้วย test set → นำไปจำแนกข้อมูลใหม่
  • Logistic Regression ทำนายความน่าจะเป็นผ่านสมการ logit และหาเส้นที่ดีที่สุดด้วย Maximum Likelihood
  • KNN ยึดหลัก "นกประเภทเดียวกันมักบินรวมฝูง" — หาเพื่อนบ้าน k ตัวที่ใกล้ที่สุด แล้วโหวต
  • KNN เป็น instance-based / lazy learner — ไม่สร้างโมเดล ต้นทุนอยู่ที่ตอนทำนาย
  • ต้องมี 3 อย่าง: ข้อมูลที่เก็บไว้ + distance metric + ค่า k
  • Euclidean distance (Minkowski ที่ q = 2) เป็นตัววัดระยะที่นิยมที่สุด
  • เลือก k จาก error rate ต่ำสุดใน validation data
  • เล็กไป = ไวต่อ noise, ใหญ่ไป = ปนคลาสอื่น
  • ต้อง scale ข้อมูล ก่อนวัดระยะทาง และต้อง แบ่ง train/test ก่อน scale เพื่อกัน data leakage
  • วัดผลด้วย confusion matrix แล้วต่อยอดเป็น Accuracy, Precision, Recall, F1
  • Accuracy อย่างเดียวไม่พอเมื่อคลาสไม่สมดุล — เลือกตัวชี้วัดตาม ต้นทุนของความผิดพลาดแต่ละแบบ
